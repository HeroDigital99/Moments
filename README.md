# موقع مصنع لحظات للشاشات الدعائية

هذه النسخة تحتوي على جميع صفحات وملفات الموقع الأصلية بدون حذف.

ابدأ من `index.html` بعد فك ضغط الملف كاملًا. استخدم شريط التنقل أو روابط المنتجات والقطاعات للانتقال بين الصفحات.

الصور والفيديوهات المحلية موجودة داخل `assets/`. الصور الخارجية الموجودة في manifest وبيانات المنتجات تحتاج اتصالًا بالإنترنت. تمت إضافة نسخة احتياطية لبيانات الجاليري حتى يعمل عند الفتح المحلي بعد فك الضغط.

---

## هيكلية المشروع (للتطوير)

```
/                          صفحات الموقع (index, about, services, products, showroom, clients, contact)
                           + product-*.html (صفحات تفاصيل المنتجات) + sector-*.html (صفحات القطاعات)
assets/
  css/style.css            نقطة الدخول: بتستورد الأجزاء بالترتيب (الترتيب مهم، اللي بعد بيغلب اللي قبل)
  css/parts/               01-base … 15-whatsapp-button  (كل ملف = قسم واحد)
  js/core/                 i18n.js (الترجمة) + main.js (القوائم، التنقل، تبديل اللغة، ظهور العناصر)
  js/features/             gallery, media, product-sliders, review-carousel,
                           text-effects (تأثير الألوان داخل الحروف), whatsapp-button
  data/                    manifest.json + manifest-data.js (بيانات المعارض) + drive-product-cards.json
  img/                     اللوجو
  media/video, posters, images    الفيديوهات والبوسترات والصور
  media/_unused/           ملفات غير مستخدمة في الموقع (mp3 وتفريغ صوتي)
docs/                      ملفات مرجعية (manus-routes.json)
```

- لتعديل قسم في التصميم: افتح ملفه في `assets/css/parts/` بدل ملف واحد ضخم.
- لإضافة قسم CSS جديد: أنشئ ملف في `parts/` وأضف سطر `@import` له في `style.css` في المكان المناسب.
- صفحات الـ HTML فضلت في الجذر بنفس أسمائها وروابطها عشان ما يتغيرش أي رابط.
